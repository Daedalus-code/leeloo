# leeloo
Multipass

This script was built on a Ubuntu Linux System (Raspberry Pi4)  

First time use:  
````git clone https://github.com/Daedalus-code/leeloo.git````  
````bash leeloo/include/install````  

Start leeloo:  
````broker````  

API Status:  
```
SouthXchange : Balance, Trade, Autotrade, Search market
StakeCube    : Balance, Search market
Poloniex     : Search market
```
